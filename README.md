# 瀬音の杜 — senoto-mori

八ヶ岳南麓・山梨県北杜市高根町にある **架空の** 渓流キャンプ場「瀬音の杜」の Web サイト。
Web サイト制作のポートフォリオとしてつくっています。

> **この施設は実在しません。** 予約は成立せず、掲載している所在地・料金・区画・お知らせは
> すべて架空です。フッタ・`/about`・`/reserve` の三か所に同じ注記を置いています。

本番: (L4 で公開予定) ／ 設計の正本: [SPEC.md](SPEC.md) ／ 検証の正本: [TEST_SPEC.md](TEST_SPEC.md)

## 何をしているサイトか

キャンプ場を探している人の関心は、だいたい四つに絞られる。

1. どの区画が空いているか
2. その区画は川に近いのか、木陰なのか
3. 何を持っていけばいいか
4. 今日そこは大丈夫か

多くのキャンプ場サイトでは、1 は外部の予約サイトに預けられ、2 は写真一枚で済まされている。
このサイトはこの四つに答えることだけを目的に組み立てている。

中心は **インタラクティブ場内図**(L2)。40 区画を画像ではなく SVG の DOM として描き、
絞り込み(川沿い / 直火可 / AC 電源 / ソロ向き)と日付が、図と一覧の両方に同時に効く。

## 背骨になっているゲート

架空の施設でも、図とデータが食い違えば嘘になる。SPEC §5 のゲートのうち、
このプロジェクトを支えているのは次の三つ。

| ゲート | 何を守っているか |
|---|---|
| **G-03** | 区画の `riverside` / `meadow` は**人手で書いたフラグ**。渓流ポリラインからの距離と森林ポリゴンの内外は**座標から独立に計算**する。両者が双方向に一致することを検査する |
| **G-04** | 料金の二実装照合。本実装と、表を引いて足すだけの素朴実装を、5 タイプ × 開場全日 227 日 × 大人 1–6 名の 6,810 通りで突き合わせる |
| **G-01** | 場内図の `data-site-id` の集合と、区画データの ID 集合が完全一致すること(L2 で追加) |

**循環の禁止** — フラグを座標から生成した瞬間、G-03 は何も検証しなくなる。
どちらか一方を他方から導いてはならない。

## 数字の出どころ

架空の場所だが、外から持ってきた数字には出典を付けている。

| データ | 出所 |
|---|---|
| 気温早見表の甲府側 | 気象庁 平年値(統計期間 1991–2020、日最低気温)・2026-08-27 取得 |
| 当地の気温 | 甲府の値から設定差分 4.7 ℃ を引いて導出。差分は架空の設定値 |
| 祝前日の判定 | 内閣府「国民の祝日」CSV を `data/syukujitsu.csv` に vendor し、`scripts/gen-holidays.mjs` で機械変換 |
| 区画数・料金・営業期間 | SPEC §2 で固定した自作の設定 |

祝日は当初 WebFetch の要約から取ろうとしたが、元日が欠落し「休日」が「休場」に化けていた。
原本を取り直して照合したことで気づいた。**要約を権威値として採らない**(loop_001 の記録)。

## 使い方

```bash
npm install
npm run dev        # http://localhost:3000
npm test           # vitest。SPEC のゲートはここに乗っている
npm run typecheck
npm run build

node scripts/gen-holidays.mjs   # 祝日表の再生成(原本を更新したときだけ)
```

## 構成

```
src/
  app/          15 ルート(App Router)
  components/   骨格(ヘッダ・フッタ・ページ枠)と shell.css
  data/         地形 geo.ts / 区画 sites.ts / 料金 pricing.ts / 気温 climate.ts / 祝日 holidays.ts(生成物)
  lib/          幾何 geometry.ts / 料金計算 pricing.ts / 営業期間 season.ts / ルート routes.ts
tests/          幾何・料金・骨格・文字種の 4 本
data/           外部データの原本(内閣府 祝日 CSV)
logs/loops/     ループログ
```

色は `src/app/globals.css` のトークンだけで定義し、コンポーネント側に生の色値を書かない
(G-09 が検査する)。
